# Ahorcado
Juego del ahorcado hecho en Ruby para practicar la sintaxis básica del lenguaje.

## Ejecución
No requiere ninguna dependencia, solo los archivos `ahorcado.rb`, `figura.rb` y `listado-general.txt` en la misma carpeta (probado con ruby 3.4.11).

Se ejecuta con `ruby ahorcado.rb <numero_letras>` donde numero_letras (opcional, por defecto 8) es el número de letras que quieres que tenga la palabra a adivinar como mínimo.

## Ejemplo de partida
```bash
  +---+
  |   |
  O   |
 /|\  |
      |
      |
=========
Palabra: a_e_re_e__e
Vidas:   2
Usadas:  d, a, o, r, e, s, v

Letra: 
```
